TailwindCSS ile CMS Projesi

React, Vite, Tailwind CSS ve React Router kullanılarak geliştirilmiş basit bir envanter / stok yönetim sistemi arayüzüdür.

# Özellikler

 -Dashboard
- Ürün listeleme
- Ürün arama
- Kategoriye göre filtreleme
- Ürün ekleme
- Ürün düzenleme
- Ürün silme
- Kategori ekleme
- Kategori silme
- Responsive tasarım
- React Router ile sayfa geçişleri


# Kullanılan Teknolojiler

- React
- Vite
- Tailwind CSS
- React Router
- Mock Data
- JavaScript
- HTML
- Tailwind CSS
